## 🌟 Features

### 📊 **Lead Management**
- ✅ Collaborative lead tracking - semua user bisa lihat semua lead
- ✅ Lead scoring & grading system (HOT, WARM, COLD)
- ✅ Lead assignment ke team members
- ✅ Advanced filtering & search
- ✅ Follow-up activity logging

### 🏗️ **Property Management**
- ✅ Unit listing & availability tracking
- ✅ Booking management dengan status workflow
- ✅ Unit reservation system
- ✅ Price & inventory management

### 👥 **User & Team Management**
- ✅ Role-based access control (Admin, Manager, Sales, Support)
- ✅ Admin-only user creation (no public registration)
- ✅ Team member assignment
- ✅ User activity tracking

### 📈 **Analytics & Reporting**
- ✅ Revenue vs Expenses dashboard
- ✅ Lead source distribution
- ✅ Pipeline status visualization
- ✅ Monthly performance trends
- ✅ Real-time statistics

### 🔒 **Security & Audit**
- ✅ Row Level Security (RLS) policies
- ✅ Audit trail untuk semua perubahan data
- ✅ Soft delete dengan recycle bin
- ✅ Data history tracking
- ✅ Activity logs

### ✨ **User Experience**
- ✅ Responsive design (mobile-friendly)
- ✅ Dark mode support
- ✅ Real-time data updates
- ✅ Toast notifications
- ✅ Loading states & error handling

## 🛠️ Tech Stack

### **Frontend**
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5.3
- **Styling:** Tailwind CSS 3.4
- **UI Components:** Radix UI + shadcn/ui
- **Icons:** Lucide React
- **Charts:** Recharts
- **Forms:** React Hook Form + Zod

### **Backend**
- **Database:** PostgreSQL (Supabase)
- **Authentication:** Supabase Auth
- **Storage:** Supabase Storage
- **Real-time:** Supabase Realtime
- **API:** Next.js API Routes (Server Actions)

### **DevOps**
- **Hosting:** Vercel
- **CI/CD:** Vercel Auto-deploy
- **Analytics:** Vercel Analytics
- **Monitoring:** Vercel Speed Insights
